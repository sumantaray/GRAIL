# Algorithm and settings

GRAIL constructs a candidate path between observed populations. A constant expression profile and a profile with an intermediate peak can share identical endpoint values. The endpoints alone cannot resolve that difference.

1. Split endpoint cells by stage (80% training, 20% test) before fitting the gene filter, highly variable genes or anchors. Apply the fixed per-cell QC threshold of 200 detected genes. Select genes expressed in at least three training cells, normalize each cell over the eligible genes to 10,000, apply log1p, and rank 2,000 features by Scanpy's Seurat normalized dispersion.
2. Use 20 random-hyperplane hash tables with 10 bits. Traverse shuffled occupied buckets across tables and sample distinct anchors per endpoint. Train the shared autoencoder on pooled A and B training anchors using mean squared error. The encoder widths are 1024, 512, 128 and 64. The decoder mirrors the hidden widths. Hidden layers use batch normalization and ReLU, and the expression output is linear.
3. During GAN training, draw a Stage A anchor code and an independent 64-dimensional standard Gaussian noise vector. Concatenate them to form the 128-dimensional generator input. Real discriminator inputs are Stage B training cells. The generator hidden widths are 128, 256 and 512. The discriminator widths are 512, 256 and 64 with LeakyReLU slope 0.2. Binary cross-entropy on logits implements the sigmoid discriminator. Use Adam with learning rate 0.0002, betas 0.5 and 0.999, real label 0.9, batch size 128 and 3,000 training iterations under the reference configuration.
4. For every Stage A anchor, find the Euclidean nearest Stage B anchor in the learned code space, allowing reuse. Interpolate along each pair with `z(t) = (1-t) zA + t zB`. Evaluate the frozen generator at `[z(t), zeros(64)]` with batch normalization in inference mode. At zero the generator receives an A code. Its training objective constrains the output distribution against B, so endpoint fidelity and condition sensitivity are tested separately.

## Choices made in the reference implementation

The manuscript does not fully specify anchor counts, AE optimizer and duration, the gradient-penalty coefficient and its exact form, or the original expression-space WD solver and scale. Here each stage supplies up to 200 anchors. The AE runs 100 epochs with Adam at 0.001. The GAN takes one sampled minibatch per algorithm iteration, uses the stated saturating minimax generator loss and a gradient-norm penalty of weight 10 on discriminator logits at interpolated real/fake inputs. Reference and example configurations record these settings. Reconstruction, GAN training and audits all use the training partition, and only the diagnostic and evaluation steps consume the held-out cells. The short example reduces the training duration, HVGs, anchors and evaluation population. These choices define this implementation.

The endpoint audit measures the autoencoder with its own decoder, plus a training-anchor mean and a dimension-matched 64-component PCA. The full model uses the GAN readout. A small reconstruction error does not uniquely determine latent interpolation paths. The encoded-intermediate audit uses standardized training-anchor coordinates, identical sampled pairs across coordinates and 256 shared Gaussian unit projections.

For expression-space WD we use exact uniform empirical Wasserstein-1 with Euclidean costs in an unwhitened 10-PC representation fitted on endpoint training cells. Matched sample sizes permit solving a linear assignment. The equal sample size is limited by the smallest evaluation population, paired sample, and a configurable cap. The same cells are used for matched, fixed-A, other-time and real-B controls. The minimum over the other intermediate coordinates is calculated within each run. The reported units belong to this representation.

For geometry, the common ten-PC fit uses training endpoints and up to 16 generated cells per method and coordinate. Evaluation uses complete population centroids on the equally spaced four-coordinate grid. TL measures total centroid displacement and AC compares successive displacement vectors. The chord and number of valid curvature terms accompany the metrics. Each method can produce different endpoint centroids. Both measures describe geometry.

Endpoint markers use rank-sum testing, Benjamini–Hochberg correction and effect-size tie breaking, up to 25 per direction. MGTC averages finite per-gene Spearman correlations across observed intermediate stages. With only two held-out stages a nonconstant gene can give only +1 or -1. DC uses ranks relative to an endpoint-derived template and is checked using the independent Table 3 script.
